# SpacemiT K1 / X60

Effective tune CPU: `spacemit-x60`; exact VLEN: 256. TTI profile:
`spacemit-k1-256`. MIR model: `spacemit-k1-direct-v1`; revision:
`k1-native-relative-v1`. [Common rules](rule.md) define units and conversions.

## Current policy

TTI uses the `spacemit-x60` subtarget's native RISC-V prices and lowering sequences.
Every operation-family coefficient is 1, including scalar/vector arithmetic,
memory, spills, casts, reductions, calls, intrinsics and constant simplification.
Native IC, probe optimization and final code generation remain native.

MIR shares [Saturn's price table](saturn.md#mir-가격과-계수) and implementation.
Vector fused FP, including widening, costs `L=max(1,data LMUL)`; ordinary vector
FP costs `2L`. Direction-specific spill/reload units Q agree with whole-register
body prices. K1 and Saturn native TTI may still differ because their subtarget
tuning differs. Geometry validation and unknown/error distinctions are shared.

Supported rules use `k1:native-relative:`; fused FP uses
`k1:native-relative-fma`. Unknowns retain explicit opcode-unknown classification.
These are relative modeling assumptions, not measured hardware service times.
The implementation is [RISCVCostSheet.cpp](../llvm/lib/Target/RISCV/RISCVCostSheet.cpp).

## Historical evidence

The preceding `k1-structural-service-v1` model used 128-bit service formulas and
iterative reference algorithms. Its 2026-11-01 validation remains under
`.cache/k1-structural-service-v1/`. Earlier `llvm-x60-occupancy-v2` transcribed
`ReleaseAtCycles` from scheduler blob `3d97bb05692912dc73c2ebbf03f121446f3331c1`.
Neither older price model is active; the native scheduler was not changed.

A retained historical sweep contains 325 kernels × six modes, 1,950 binaries and
5,850 successful samples. `.cache/k1-costsheet-review/` records ELF/source hash
checks; `.cache/scalar-cost-unification/` records staged selection diagnostics.
These artifacts belong to earlier compilers.
Timing variation for identical ELFs prevents reverse-engineering
instruction prices from those samples.

The 2026-11-03 native-relative implementation checks and single-case
`rajaperf/stream-triad` six-mode build were historical software checks, not hardware
measurements. Their temporary outputs were deleted; identical execution images
caused ELF publication to be omitted. No hardware speedup is claimed.
