# SpacemiT K1 / X60 CostSheet

선택: `-mcpu=spacemit-x60 -mrvv-vector-bits=256` 또는 같은 effective tune CPU.
Model `spacemit-k1-direct-v1`, TTI profile `spacemit-k1-256`.
[공통 규칙](rule.md)을 따른다. 표준 scalar/RVV 대상이며 IME 자동 lowering은 없다.

## 출처

[공식 K1 Datasheet V7.1](https://github.com/spacemit-com/docs-chip/blob/main/en/key_stone/k1/k1_docs/k1_ds.md),
[CPU manual §8](https://github.com/spacemit-com/docs-chip/blob/main/en/key_stone/k1/k1_docs/k1_usermanual/8.CPU_System.md),
[X60 제품 설명](https://www.spacemit.com/products/ai-compute-core/x60)에서
RVV1.0/VLEN256, 8-stage dual-issue in-order, core별 L1와 cluster별 L2를 확인한다.
CPU functional 설명은 Reserved이며 명령별 가격을 공개하지 않는다.
SoC TOPS는 RVV 비용의 근거가 아니다.

상세 가격의 보조 출처는 이 checkout의
[RISCVSchedSpacemitX60.td](../llvm/lib/Target/RISCV/RISCVSchedSpacemitX60.td)다.
그 파일은 C908 문서와 BPI-F3 실험 기반이며 K1 공식 보장값이 아니다.
가격을 전사한 scheduler의 Git blob은 `3d97bb05692912dc73c2ebbf03f121446f3331c1`이다.
Model revision `llvm-x60-occupancy-v1`은 아래 전사 규칙의 버전이다.
Runtime에 scheduler/llvm-mca를 호출하지 않는다. Scheduler 변경도 표를 자동 변경하지 않는다.

## 실제 가격

L=max(1,LMUL), B=256*data EMUL, N=max(1,B/EEW); 산술은 EEW=SEW다.
위에서 아래로 적용한다. Fractional geometry는 공통 검증을 따른다.

| 명령군 | 비용 | 근거 |
|---|---|---|
| Whole-register load/store g=1/2/4/8 | 3/4/8/16 | schedule occupancy |
| Whole-register copy g=1/2/4/8 | 4/4/8/16 | schedule occupancy |
| Segment memory F fields | NF | schedule occupancy |
| Indexed memory | max(1,floor(N/2)) | schedule occupancy |
| Strided memory | N | schedule occupancy |
| Contiguous load | max(3,2L) | schedule occupancy; fractional도 3 |
| Contiguous store | fractional 2; m1/m2/m4/m8=3/4/8/19 | schedule occupancy |
| Integer divide/remainder | 12*max(1,2LMUL) | grouped schedule occupancy |
| Vector FP divide/reverse/sqrt | L*k | schedule occupancy, k는 아래 정의 |
| Reduction | integer N, FP 4N | 직렬 reduction 가정 |
| Gather/compress/slide | 2N | element별 permutation 가정 |
| VW/VFW/VNS/VNC/VFNC prefix의 지원 연산 | max(1,2LMUL) | 넓은 데이터 service 대표값 가정 |
| VADD/VSUB/VRSUB/VAND/VOR/VXOR 계열 | max(1,2LMUL) | grouped ALU schedule occupancy |
| 기타 지원 SIMD | L | SIMD group 가정 |
| Scalar integer divide/remainder W / XLEN | 12 / 20 | schedule occupancy |
| Scalar FP divide/sqrt H/S/D | 12/15/22 | 보수적인 grouped schedule 값 |
| 기타 scalar/configuration | 1 | nominal 기본 가정 |

FP k: VF operand 형태는 SEW64일 때40, 나머지12. VV/sqrt는 SEW16일 때12, 나머지40.
같은 schedule class로 묶인 값은 일부 명령을 비싸게 평가한다. Latency 합산은 아니다.
FP reduction/permutation 등은 상세 schedule의 서로 다른 의존성·분류를 섞지 않고
위 단순값을 명시적으로 채택했다. 실측 평균을 주장하지 않는다.

이 표의 wide-service 분기는 위에 명시한 opcode prefix에만 적용한다.
`VSEXT_VF2/4/8`, `VZEXT_VF2/4/8`은 기타 지원 SIMD의 `L` 가격을 사용한다.

## Spill과 adapter

Vector f(g)는 whole-register load/store와 같다. Scalar는 방향별 Q다.
추정 n개는 방향별3n, 관측 group4 한 쌍은16이다.
`{1,1,4}`는14, `{2,2,2}`는12다. TTI와 SpacemitK1MIRInfo는 같은 sheet를 쓴다.
TTI에 없는 index geometry는 native 추정을 쓴다. Native scheduler는 upstream
구현을 유지하며 후보 cost scope 밖에는 새 가격을 적용하지 않는다.
Cache miss, WAW, dual-pipe overlap, 실제 bank 배치는 모델링하지 않는다.
